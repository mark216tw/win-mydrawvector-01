---

## 1. 產品定位

MyDrawVector 是一套免安裝、完全離線的 Windows 向量繪圖軟體，讓學生可以快速完成學習單、海報、卡片、漫畫格與課堂作品。設計重點是：

- 圖示化、低學習門檻的操作介面。
- 完整的復原與自動儲存，降低誤操作成本。
- 向量物件可自由移動、縮放、旋轉與翻轉。
- 作品可存成單一 `.mydraw` 檔案，也可匯出 PNG。
- 不依賴網路、帳號或雲端服務。

## 4. 互動規格

| 操作 | 規格 |

## 5. 物件模型

```text
SceneObject
├── ShapeObject
├── TextObject
├── ImageObject
└── PathObject
```

共同欄位：

- `Id`、`Name`、`LayerId`、`ZIndex`
- `Transform`：中心、寬高、旋轉、翻轉
- `Opacity`、`IsVisible`、`IsLocked`

圖形種類：

- `Rectangle`、`RoundedRectangle`、`Ellipse`、`Line`、`Arrow`
- `Triangle`、`Diamond`、`Pentagon`、`Hexagon`、`Star`、`SpeechBubble`

文字欄位：

- 內容、字型、字級、字重、粗體、斜體、底線、顏色、對齊、行距。

圖片欄位：

- 資產 ID、顯示方式。

路徑欄位：

- 正規化點集合、線條顏色、粗細、樣式。

## 6. 檔案格式

`.mydraw` 是 ZIP 容器：

```text
manifest.json     schema、版本、appVersion、建立／修改時間
document.json     畫布、圖層、物件、樣式、資產參照
assets/           圖片資產
```

- 容器版本目前為 2。
- 文件 JSON 使用 CamelCase 與字串列舉。
- 儲存採原子寫入。
- 舊版沒有圖層欄位的文件會在載入時自動遷移。
- 資產檔名會做路徑安全檢查。
- 缺少資產不影響文件開啟。

## 8. 設定與主題

`%AppData%\MyDrawVector\settings.json` 保存：

- 視窗位置、大小、最大化狀態。
- 顯示格線、吸附、自動選取工具。
- 顯示模式與主題顏色。
- 每個圖形工具與文字工具的樣式。
- 鉛筆樣式。
- 最近檔案清單（最多 10 筆）。

顯示模式：

- 跟隨系統
- 淺色
- 深色

主題顏色：

- 經典藍、天空藍、青綠、森林綠、護眼黃、活力橙、珊瑚紅、暮色紫、玫瑰粉、中性灰。

## 10. 效能與品質

目標：

- 一般教材文件可流暢縮放與平移。
- 開檔、存檔、匯出 PNG 在合理時間內完成。
- 啟動後可快速顯示主視窗。

目前策略：

- 視覺元素依物件 ID 快取。
- 筆刷快取。
- 格線快取。
- 自動儲存以 `ChangeVersion` 去重。
- 圖片資產以 SHA-256 去重。
