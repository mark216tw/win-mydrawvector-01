# MyDrawVector 使用指南

- 文件版本：1.0
- 對應軟體版本：1.6.12
- 適用對象：國小、國中、高中學生與一般使用者
- 平台：Windows 10 1809 以上（x64／ARM64）

---

## 1. 安裝與啟動

### 1.1 取得程式

1. 前往 GitHub Releases 下載對應架構的壓縮檔：
   - x64：`MyDrawVector-1.6.12-portable-win-x64.zip`
   - ARM64：`MyDrawVector-1.6.12-portable-win-arm64.zip`
2. 將 zip 解壓縮到任意資料夾，例如 `D:\Apps\MyDrawVector`。
3. 確認資料夾內有 `MyDrawVector.exe`、`MyDrawVector.pri`、`Assets` 與所有 DLL。

### 1.2 安裝執行環境

本版本為 **非 self-contained** 發行，需先安裝：

- .NET 10 Desktop Runtime（與程式相同架構）
- Windows App SDK 2.6.5 Runtime（與程式相同架構）

> 若在 ARM64 裝置上執行 x64 版本，系統會透過模擬執行，速度較慢；建議下載 ARM64 版本。

### 1.3 啟動

雙擊 `MyDrawVector.exe`。第一次啟動時：

1. 建立使用者設定與日誌資料夾。
2. 檢查 `.mydraw` 檔案關聯，必要時自動寫入 `HKCU\Software\Classes`。
3. 顯示主視窗並套用上次的視窗位置、顯示模式與主題顏色。

程式採單一實例設計。再次啟動時會把既有視窗帶到前景，並開啟命令列或檔案關聯帶入的 `.mydraw` 檔案。

### 1.4 移除

本程式不需要解除安裝：

1. 關閉 MyDrawVector。
2. 由「設定 → 偏好設定 → 移除檔案關聯」移除 `.mydraw` 關聯（或執行 `MyDrawVector.exe --unregister`）。
3. 刪除程式資料夾。
4. 如需清除個人設定，可刪除 `%AppData%\MyDrawVector` 與 `%LocalAppData%\MyDrawVector`。

## 2. 介面導覽

### 2.1 選單列

| 選單 | 內容 |
| --- | --- |
| 檔案 | 新增、開啟、最近開啟、儲存、另存新檔、匯出 PNG |
| 編輯 | 復原、重做、剪下、複製、貼上、再製、刪除、全選 |
| 設定 | 偏好設定 |
| 說明 | 快捷鍵一覽、關於 MyDrawVector |

### 2.2 左側工具列

由上而下依序為：

- 復原、重做
- 選取（V）
- 矩形（R）
- 鉛筆（P）
- 橢圓（E）
- 直線（L）
- 文字（T）
- 插入圖片（I）
- 平移（H）
- 更多圖形：圓角矩形、箭頭、三角形、菱形、五邊形、六邊形、星形、對話框

每個工具都有工具提示與螢幕閱讀器名稱。按一下工具即可切換；插入圖片是立即動作，會直接開啟檔案選擇對話框。

### 2.3 畫布區

畫布由多層組成：

- 頁面底色與陰影
- 透明棋盤格（僅透明背景時顯示）
- 格線
- 物件層
- 預覽層（建立圖形、框選、鉛筆）
- 選取框、8 個控制點與旋轉手柄
- 浮動選取工具列

畫紙外的內容會被裁切，不會顯示，也不會匯出。

### 2.4 屬性面板

屬性面板分為三個頁籤：

| 頁籤 | 內容 |
| --- | --- |
| 物件 | 圖形樣式、透明度、旋轉與翻轉、文字屬性、圖片屬性 |
| 圖層 | 圖層清單、目前圖層物件、顯示／鎖定、新增／改名／刪除／排序 |
| 畫布 | 顯示格線、吸附至格線、點擊物件自動選擇選取工具、畫布尺寸、畫布背景 |

在畫布上選取物件時會自動切到「物件」頁籤；從圖層清單點選物件則不會強制切換。

### 2.5 狀態列

狀態列顯示：

- 目前畫布尺寸（例如「A4 橫式」）
- 選取摘要（例如「矩形 1」或「已選取 3 個物件」）
- 格線與吸附狀態
- 縮放百分比
- 最近一次自動儲存時間

### 2.6 浮動選取工具列

單選物件時，選取框下方會顯示浮動工具列，提供：

- 旋轉 90°
- 水平翻轉
- 垂直翻轉
- 再製
- 刪除

多選時只顯示可套用於多個物件的動作。工具列會避開選取框與旋轉手柄；空間不足時移到選取框上方。

## 3. 檔案操作

### 3.1 新增文件

- 選單「檔案 → 新增」或 `Ctrl+N`。
- 若目前文件有未儲存變更，會先詢問是否儲存。
- 新文件使用 A4 橫式與白色背景。

### 3.2 開啟文件

- 選單「檔案 → 開啟」或 `Ctrl+O`。
- 可從「檔案 → 最近開啟」快速開啟最近 10 個檔案。
- 也可直接雙擊 `.mydraw` 檔案，或把檔案拖放到視窗。

### 3.3 儲存與另存新檔

- `Ctrl+S`：儲存目前文件；沒有路徑時會開啟另存對話框。
- `Ctrl+Shift+S`：另存新檔。
- 檔名會自動補上 `.mydraw` 副檔名。
- 標題列出現 `*` 表示有未儲存變更。

### 3.4 匯出 PNG

由「檔案 → 匯出 PNG」選擇：

- 倍率：1×、2×、3×。
- 是否保留文件背景透明度。

匯出範圍為整張畫布，畫紙外內容不會包含。透明背景文件可輸出透明 PNG。

### 3.5 關閉程式

若有未儲存變更，關閉前會詢問「儲存／不儲存／取消」。選擇「不儲存」後仍會保留自動儲存檔，下次啟動可選擇恢復。

## 4. 畫布操作

### 4.1 縮放

| 操作 | 功能 |
| --- | --- |
| 滑鼠滾輪 | 以游標位置為中心放大或縮小 |
| `Ctrl++` / `Ctrl+-` | 放大／縮小 |
| `Ctrl+0` | 重設為 100% |
| `Ctrl+1` | 適合視窗 |
| 狀態列縮放滑桿 | 10%～800% |

### 4.2 平移

- 按住空白鍵拖曳。
- 按住滑鼠中鍵拖曳。
- 按住滑鼠右鍵拖曳。
- 選擇平移工具（H）後拖曳。

平移會限制在合理範圍，畫紙四邊至少保留 40 DIP 可見。

### 4.3 畫布設定

在屬性面板「畫布」頁籤：

- **顯示格線**：顯示 20 DIP 格線，每 100 DIP 為較深的主格線。
- **吸附至格線**：移動、縮放與建立圖形時，在 8 DIP 內吸附格線。
- **點擊物件自動選擇選取工具**：開啟後，用任何工具點擊既有物件會自動切回選取工具。預設關閉。
- **畫布尺寸**：A4 橫式、A4 直式、A3、Letter、16:9。
- **畫布背景**：白、淺灰、灰、黑、米色、淺藍、淺綠、淺黃、淺粉與透明。

拖曳時按住 `Alt` 可暫時關閉吸附。

---

## 5. 建立圖形

### 5.1 拖曳建立

1. 選擇圖形工具。
2. 在畫布上按住左鍵拖曳。
3. 放開後建立圖形。

- 按住 `Shift` 可建立正方形或正圓。
- 拖曳距離太小（寬或高小於 8 DIP）時，會建立預設大小的圖形。
- 由下往上或由右往左拖曳時，會自動設定水平／垂直翻轉。

### 5.2 圖形樣式

在屬性面板「物件」頁籤可調整：

- 啟用填色、啟用邊框
- 填色與邊框顏色（20 色快速色盤與自訂顏色）
- 邊框粗細
- 線條樣式（實線、虛線、點線）
- 圓角（僅圓角矩形）
- 透明度
- 旋轉角度與翻轉

每個圖形工具會分別記住自己的樣式，下次使用同一工具時自動套用。

### 5.3 線條與箭頭

- 線條與箭頭不填色，一定有邊框。
- 箭頭頭部長度會依線段長度調整。
- 選取範圍為整個矩形框，不需要精準點在線條上。

---

## 6. 文字

### 6.1 新增文字

1. 選擇文字工具（T）。
2. 在畫布上點一下。
3. 在「新增文字」對話框輸入內容。
4. 按「確定」建立文字；按「取消」不會建立物件。

新文字會沿用上次使用的字型、字級、字重、斜體、底線、顏色、對齊與行距。

### 6.2 編輯文字

- 使用選取工具，雙擊既有文字。
- 在對話框中修改內容後按「確定」。
- 修改文字會成為一筆復原紀錄。

### 6.3 文字屬性

- 字型：常用中英文字型清單。
- 字級：6～300。
- 字重：細、一般、半粗、粗、特粗。
- 斜體、底線。
- 文字顏色。
- 對齊：左、中、右。
- 行距。
- 文字框會自動換行。

> 文字編輯目前使用對話框；旋轉文字在編輯時不會以旋轉角度顯示，完成後會套回原本的變形。

---

## 7. 圖片

### 7.1 插入圖片

- 按工具列的「插入圖片」（I），選擇 PNG、JPEG、BMP 或 GIF 檔案。
- 由剪貼簿貼上點陣圖。
- 直接把圖片檔拖放到視窗。

插入後圖片會置於頁面中央，過大時會等比例縮小到頁面約 55%。

### 7.2 替換圖片

選取圖片後，在屬性面板按「替換圖片」，選擇新檔案。新圖片會沿用目前物件的位置、大小與變形。

### 7.3 縮放

- 拖曳控制點可縮放。
- 圖片預設鎖定比例；按住 `Shift` 可解除比例鎖定。
- 圖片資產以 SHA-256 去重，同一張圖片重複插入只會保存一份。

### 7.4 遺失資產

若文件中的圖片資產遺失，畫布會顯示半透明佔位狀態，文件仍可正常開啟與儲存。

---

## 8. 鉛筆與自由筆畫

1. 選擇鉛筆工具（P）。
2. 在畫布上拖曳繪製。
3. 放開後建立向量路徑物件。

- 單點擊會建立一個小圓點。
- 線條顏色、粗細與樣式可在屬性面板「筆畫」區塊調整。
- 建立後的筆畫可移動、縮放、旋轉與翻轉。
- 目前不提供節點編輯。

---

## 9. 選取與變形

### 9.1 選取

| 操作 | 功能 |
| --- | --- |
| 點擊物件 | 單選 |
| `Ctrl` 或 `Shift` 點擊 | 加入或移除選取 |
| 在空白處拖曳 | 框選 |
| `Ctrl+A` | 全選 |
| `Tab` / `Shift+Tab` | 依序切換物件 |
| `Esc` | 清除選取 |

任何工具下都可以點擊既有物件選取；選取後可直接拖曳、縮放、旋轉與調整屬性，工具不會自動改變（除非開啟「點擊物件自動選擇選取工具」）。

### 9.2 移動

- 直接拖曳選取物件。
- 方向鍵微調 1 DIP，`Shift`+方向鍵微調 10 DIP。
- 開啟吸附時，移動會在 8 DIP 內吸附格線。

### 9.3 縮放

- 單選時顯示 8 個控制點：四角與四邊中點。
- 拖曳控制點縮放；對角控制點固定。
- 一般物件按 `Shift` 鎖定比例，圖片預設鎖定比例、按 `Shift` 解除。
- 最小物件尺寸為 8 DIP。

### 9.4 旋轉

- 拖曳上方圓形手柄旋轉。
- 按住 `Shift` 每 15° 吸附。
- 屬性面板提供 0／90／180／270 快速按鈕與角度數值欄位。

### 9.5 翻轉

- 屬性面板或浮動工具列提供水平翻轉與垂直翻轉。
- 以物件中心為軸翻轉，會保留翻轉狀態。

### 9.6 物件順序與對齊

- 屬性面板「物件」頁籤提供上移、下移、置頂、置底。
- 對齊：左、中、右、上、中、下。
- 多選時可對齊多個物件。

## 10. 圖層

在屬性面板「圖層」頁籤：

- 新增圖層、改名、刪除、上下移動。
- 切換顯示／隱藏與鎖定。
- 查看目前圖層的物件清單。
- 新增物件、貼上與再製會放入目前圖層。

刪除圖層時：

- 空白圖層會直接刪除。
- 有物件的圖層會先確認。
- 最後一個圖層不可刪除。

隱藏圖層的物件不會顯示，也不會被選取；鎖定圖層的物件只能從圖層清單操作。

---

## 11. 剪貼簿

- **內部物件**：複製／剪下後貼上，會保留物件樹與圖片資產，貼上時位移 16 DIP 並重新命名。
- **外部圖片**：從其他程式複製圖片後貼上，會建立圖片物件。
- **外部文字**：從其他程式複製純文字後貼上，會建立文字物件。
- **拖放**：可把 `.mydraw` 或圖片檔拖放到視窗。

---

## 12. 復原與重做

- `Ctrl+Z` 復原，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- 復原歷史至少 100 步。
- 連續拖曳、色盤連點與數值連按會合併為一筆。
- 復原後會盡量保留原本的選取物件。
- 刪除物件後，畫布下方會顯示「已刪除，復原」提示約 6 秒，可直接復原。

---

## 13. 自動儲存與當機恢復

- 文件有變更時，每 60 秒自動儲存一次。
- 自動儲存位置：`%LocalAppData%\MyDrawVector\Autosave`。
- 正常儲存或選擇不儲存後，自動儲存檔會刪除。
- 若程式異常結束，下次啟動會詢問「恢復／捨棄／稍後」。
  - **恢復**：開啟自動儲存內容，並保留原始檔案路徑，需再按儲存才會覆寫原檔。
  - **捨棄**：刪除自動儲存檔。
  - **稍後**：保留檔案，下次啟動再詢問。

> 若在第一次自動儲存前當機，可能無法恢復最新變更。

---

## 14. 設定與主題

由「設定 → 偏好設定」可調整：

- 顯示模式：跟隨系統、淺色、深色。
- 主題顏色：經典藍、天空藍、青綠、森林綠、護眼黃、活力橙、珊瑚紅、暮色紫、玫瑰粉、中性灰。
- `.mydraw` 檔案關聯：建立／更新、移除。

主題顏色會即時套用，不需要按「套用」。高對比模式會使用系統強調色，不覆寫自訂主題顏色。

視窗位置與大小會在關閉時保存；下次啟動會依目前螢幕與工作區驗證後還原，若超出可見範圍會自動調整。

---

## 15. 檔案關聯

- 第一次啟動會自動建立 `.mydraw` 關聯。
- 關聯只寫入 `HKCU\Software\Classes`，不需要系統管理員權限。
- 搬移程式資料夾後，重新執行 exe 或由偏好設定更新關聯。
- 命令列：
  - `MyDrawVector.exe --register`：建立／更新關聯後直接結束。
  - `MyDrawVector.exe --unregister`：移除關聯後直接結束。
- 進階：設定環境變數 `MYDRAWVECTOR_DISABLE_ASSOC=1` 可停用啟動時自動建立關聯。

## 17. 疑難排解

### 17.1 程式無法啟動

1. 確認已安裝 .NET 10 Desktop Runtime 與 Windows App SDK 2.6.5 Runtime。
2. 確認架構正確：x64 版需要 x64 Runtime，ARM64 版需要 ARM64 Runtime。
3. 查看 `%LocalAppData%\MyDrawVector\Logs\app.log` 的錯誤訊息。
4. 確認 `MyDrawVector.pri` 與所有 DLL 都在程式資料夾內。

### 17.2 開啟 `.mydraw` 沒有反應

- 重新執行 `MyDrawVector.exe` 一次，讓程式自動修復關聯。
- 或由「設定 → 偏好設定 → 建立／更新檔案關聯」手動更新。
- 也可以直接把檔案拖放到已開啟的 MyDrawVector 視窗。

### 17.3 圖片顯示為半透明

- 代表文件中的圖片資產遺失。
- 可用「替換圖片」重新指定檔案，或復原到先前的版本。

### 17.4 自動儲存沒有恢復

- 自動儲存每 60 秒才寫入一次；若在第一次寫入前當機，可能沒有可恢復的檔案。
- 檢查 `%LocalAppData%\MyDrawVector\Autosave` 是否存在 `autosave.mydraw` 與 `autosave.json`。

### 17.5 介面文字太小或版面擁擠

- 使用 Windows 顯示設定調整縮放比例。
- 視窗有最小尺寸限制（1024×700）；若螢幕解析度較低，請先調整系統縮放。

## 18. 隱私

MyDrawVector 完全離線運作：

- 不上傳作品、圖片、檔案路徑或使用紀錄。
- 不包含帳號、雲端同步或廣告。
- 設定與日誌只寫入目前使用者的本機資料夾。

---

## 19. 已知限制

- 尚未實作群組／解群組、智慧參考線、範本庫、均分、物件跨圖層搬移。
- 尚未實作 SVG／JPG／PDF 匯出與列印。
- 文字編輯使用對話框；旋轉文字編輯時不會即時顯示旋轉角度。
- 尚未支援雙指縮放、觸控筆壓感、圖片裁切。
- 字型清單以常用字型為主，缺少文件使用的字型時會以系統字型呈現。
- ARM64 版本已完成建置與封裝，但尚未在實體 ARM64 裝置上完成完整手動測試。
- 高 DPI、Windows 10 1809 與高對比模式仍建議實際測試。
